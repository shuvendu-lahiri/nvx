# NVX NFV audit reports

[Open the live dashboard](https://shuvendu-lahiri.github.io/nvx/nfv_reports/) or
read the [GitHub-readable dashboard](nfv_reports/README.md).

This reports-only branch tracks twenty historical source changes by Pedro
Henrique Penna. The source is never executed or merged. Refutations are
conditional MODEL refutations, not confirmed source bugs; verification concerns
translated models under their assumptions.

The fork's `dev` branch is unchanged. Original source links use GitHub's
no-backlink redirect, and each replay links its generated report and workflow
evidence. Waiting, in-progress and failed audits are not zero-finding results.

The dashboard implementation is adapted from the LiteBox NFV dashboard, with
the visual layout inspired by CoZ3.
